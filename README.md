## 📝 Project Overview
This project was developed for an internship task to master **Bootstrap 5**. The goal was to **remix** official UI patterns to build a responsive, modern multi-page website.

The site consists of:
1. **Home Page**: Includes a hero section, responsive feature grid, and dark navbar.
2. **About Page**: Features a mission statement and team section.
3. **Contact Page**: Includes a responsive form and contact details.

---

* **HTML5 & CSS3**: Structural markup and custom animations.
* **Bootstrap 5.3**: Grid system and components.
* **Bootstrap Icons**: Integrated for visual features.
* **Git & GitHub**: Version control and hosting.

## 🧠 Reflection Report

### 1. Component Selection & Remixing
Instead of using full templates, I extracted specific UI patterns:
* **Navbars**: Adapted a `sticky-top` navbar with custom hover animations.
* **Heroes**: Modified the hero pattern and updated buttons for page navigation.
* **Features**: Implemented a 3-column grid that collapses gracefully on mobile.

### 2. Styling & Visual Appeal
* **Custom Color Palette**: Overrode defaults with an **Indigo (#6366f1)** theme.
* **Transitions**: Added CSS animations for page fade-in and card hover states.
* **Typography**: Integrated the **Inter** font for a cleaner aesthetic.

### 3. Challenges Overcome
* **Git Configuration**: Resolved `user.name` errors using global configuration commands.
* **Terminal Error**: Fixed "ConPTY" launch issues by adjusting VS Code renderer settings.
* **Icon Rendering**: Corrected placeholder squares by linking the Bootstrap Icons CDN.
